## 🚀 Caratteristiche Principali

- **Ricerca Unificata**: Interroga contemporaneamente i repository ufficiali di Arch (`pacman`) e l'AUR (`yay`).
- **Gestione Dettagliata**: Schermata di dettaglio per ogni pacchetto con licenze, dipendenze complete, voti, popolarità e link ufficiali cliccabili.
- **Aggiornamenti Sicuri e Sequenziali**: Sistema di aggiornamento massivo intelligente che non si blocca in caso di errori di compilazione AUR, mostrando un report grafico dettagliato e lo storico degli errori per singolo pacchetto.
- **Gestione Pacchetti Installati**: Tab dedicata per monitorare tutti i pacchetti attivi sul sistema con possibilità di disinstallazione rapida.
- **Autenticazione Sudo Integrata**: Gestione sicura dei permessi di root con password streaming in tempo reale.
- **UI Material 3**: Interfaccia grafica nativa, pulita e reattiva progettata specificamente per Linux.
